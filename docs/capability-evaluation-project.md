# Capability Evaluation Project

English | [中文](capability-evaluation-project.zh.md)

## Principles

> **Scope of this document** — this project decomposes Agent Assistance's purposeful capabilities into generalizable capability slices and tasks, progressively building a repeatable evaluation, regression, coverage, and evolution system; it defines capability planning, generalization tasks, evaluation projects, coverage, and evolution, with the Case Runner as one evaluation vehicle among them, and it does not define the agent's final capability goals (see `docs/agent-assistance.md`) or the Case Runner's format and execution mechanism (see `docs/case-runner.md`).
